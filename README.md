# Chefi

Early PlatformIO project for a compact cooking assistant prototype.

## Current state

This repository contains the initial ESP32-S3 project configuration and starter Arduino code. Camera, microphone, speaker, AI service, and mounting features have not yet been implemented.

## Development

Open this folder in PlatformIO. The configured board is `dfrobot_firebeetle2_esp32s3`.

```sh
pio run
```

## Project structure

- `src/main.cpp` — starter firmware
- `platformio.ini` — board and framework configuration
- `include/`, `lib/`, `test/` — standard PlatformIO directories
